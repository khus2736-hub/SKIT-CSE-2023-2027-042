# Amagen EMS — Frontend (React 18 + Vite)

Employee Management and Task Monitoring System for Amagen Pharma Private Limited.

## Requirements
- Node.js 18+
- npm 9+

## Running the Frontend

```bash
npm install
npm run dev
```

The frontend will run on `http://localhost:5173`.
All requests to `/api` are automatically proxied to the Spring Boot backend on `http://localhost:8080`.
